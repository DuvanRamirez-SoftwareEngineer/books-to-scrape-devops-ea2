Books to Scrape – Proyecto DevOps

Evidencia de Aprendizaje 2 · Programación para Análisis de Datos

Duván Oswaldo Ramírez Duarte

Descripción

Continuación de la Evidencia 1: extracción de título, precio, disponibilidad y enlace de libros del catálogo de práctica Books to Scrape.

Flujo DevOps

  1. Git administra el historial de cambios.
  2. GitHub aloja el repositorio y permite trabajar con ramas y Pull Requests.
  3. GitHub Actions instala dependencias y ejecuta pruebas automatizadas con pytest.
  4. Si las pruebas pasan y el cambio llega a main, se publica esta documentación en GitHub Pages.

Validaciones automatizadas

Las pruebas comprueban extracción de campos, construcción de URL, detección de valores vacíos y duplicados. Se utiliza HTML de prueba para no depender de la conexión externa durante CI.

Repositorio y código

El código fuente, notebook original, pruebas y configuración de automatización se encuentran en el repositorio GitHub del proyecto.
